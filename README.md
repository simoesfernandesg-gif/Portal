#  Meu Portal de Entretenimento Digital :sparkling_heart:

Bem-vindo ao **Meu Portal de Entretenimento Digital**, um site interativo desenvolvido para centralizar meus conteúdos favoritos de entretenimento, cultura pop, música, podcasts, linguagens de programação e ferramentas de tecnologia!


---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias básicas de desenvolvimento web:

* **HTML5**: Estruturação  das páginas e seções de conteúdo.
* **CSS3**: Estilização visual, layout responsivo e organização dos elementos.


---

## 📂 Estrutura do Projeto

O portal está organizado nas seguintes categorias principais:


1. **Filmes e Séries**
2. **Música e Podcasts**
3. **Games e Tecnologia**
